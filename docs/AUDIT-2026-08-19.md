## 3. Mineurs

- `.env.example` incomplet (VAPID, `WHATSAPP_ACCESS_TOKEN`, `AT_*`, `FROM_*`, `SUPABASE_ACCESS_TOKEN`, `DATABASE_URL`, JWKS).
- `fn_audit_log_change` `SECURITY DEFINER` sans `search_path` explicite.
- `GET /api/push-subscribe` sans rateLimit.
- ThemeToggle sur deux systèmes de clés (`allotechno_theme` vs `at-theme`).
- Nav dupliquée dans le Header (2× `aria-label="Utility"`), textes en dur non i18n.
- `AdminSectionTabs` : `role="tablist"` incomplet (pas de `tab`/`tabpanel` associés).
- Double lockfile `package-lock.json` + `bun.lock` désynchronisés ; vérif `deploy.yml:17-18` cosmétique (grep non bloquant).
- Nitro en `beta` en prod ; 5 fichiers > 1100 lignes.
- `og-image.png` 149 Ko (PNG, pas de webp/avif/srcset) ; icônes 512 = 163 Ko.
- Pas de `Product` schema, pas de `cache-control` sur les assets.
- `roles.spec.ts` hardcode `Demo@2026` ; `monitoring.ts` buffer en mémoire perdu entre isolats ; `analytics.functions` `console.warn` silencieux.
- `historique.tsx` `noindex` sans canonical ; `app.tsx`/`demo.tsx` sans meta robots.
- `VITE_SUPABASE_PROJECT_ID` définie dans les workflows mais jamais utilisée dans `src/`.
- `.env.example` `VITE_SUPABASE_PUBLISHABLE_KEY` vs workflows `VITE_SUPABASE_KEY` (compensé par fallback `client.ts:11-12`).
- Rejets webhook (signature/paiement) non audités en base.
- Versions flottantes : `npx --yes supabase`, `wrangler-action@v3` installe sa propre copie de wrangler (drift vs `wrangler ^4.120.0` local).
- Backups éphémères : artifact 30 j, logique « keep last 7 » morte en CI, aucun stockage durable (R2/S3).

## 4. Points forts confirmés

- **Sécurité** : CSP stricte à nonce, HSTS, middleware CSRF, comparaisons `safeEqual` pour les crons ; webhooks entrants bien signés (HMAC + fenêtre 5 min + montant + idempotence) ; aucun secret dans git ; secret workflow GitHub créés via libsodium.
- **Qualité** : `tsc --noEmit` 0 erreur, eslint 0 warning, vitest 114/114, build OK, 24 runs CI/Deploy verts consécutifs.
- **Backup** : réparé (18/08) — `supabase link` + `db dump` via API, run 5 vérifié (artifact 53 Ko), cron hebdomadaire.
- **Perf** : code-splitting manuel bien conçu (catalog/vendor-xlsx/vendor-qr en chunks lazy), routeRules de cache sur blog/catalogue, i18n lazy des segments lourds (admin/org/mon-compte).
- **Rendu** : PWA complète, pages 404/error custom, `ContactForm` (focus trap/Échap) exemplaire, RLS durcie itérativement (b44), WebSocket Realtime sous CSP corrigé (b46).
